# Manufacturing Suppliers

This directory is used to organize prototype manufacturers, PCB assembly suppliers, EMS partners, contract manufacturers, quotations, capability documents, NDA status, and supplier evaluations for Magen Daniel Systems LLP.

## Directory Structure

- `india/` - India-based suppliers and EMS partners.
- `global/` - Non-India suppliers and global manufacturing partners.
- `rfq-templates/` - RFQ and enquiry templates.
- `supplier-evaluation/` - Evaluation checklists and comparison templates.
- `nda-status/` - NDA tracking and compliance notes.

## Confidentiality

Do not upload sensitive technical production files to a public repository, including Gerber files, schematics, BOM, firmware, PCB layout files, test firmware, NDA-signed documents, confidential quotations, or patent-sensitive architecture details unless the repository is private and access controlled.

Capability brochures, public company profiles, high-level supplier notes, and non-confidential evaluation summaries may be stored here.
