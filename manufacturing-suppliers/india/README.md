# India Manufacturing Suppliers

This directory contains India-based PCB fabrication companies, SMT assembly suppliers, EMS providers, prototype manufacturers, box-build partners, and related supplier evaluation notes.

## Supplier Categories

- PCB fabrication
- SMT assembly
- EMS / contract manufacturing
- Prototype electronics manufacturing
- Firmware flashing and functional testing
- Enclosure / box-build support
- Rework and repair support

## Review Priority

1. Capability documents
2. NDA readiness
3. Prototype quantity support
4. BOM sourcing capability
5. Firmware flashing support
6. Functional testing support
7. QC reports and serial number tracking
8. MOQ and lead time
9. Facility visit or video call
